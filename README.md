# Titanic Data Cleaning Pipeline

## 📌 Project Overview
This project demonstrates a complete data cleaning and preprocessing pipeline using Python and Pandas. The goal was to take a raw, messy dataset (the famous Titanic dataset) and prepare it for a Machine Learning model.

## 🛠️ Skills Used
*   **Python & Pandas:** For data manipulation.
*   **Data Imputation:** Filled missing numerical values (`age`, `fare`) using the mean.
*   **Categorical Encoding:** Transformed text columns (`sex`, `embarked`) into machine-readable numbers.
*   **Scaling:** Used `StandardScaler` to normalize the data for Neural Networks.
*   **PyTorch:** Converted the final cleaned DataFrame into PyTorch Tensors.

## 📂 Files in this Repository
*   `Titanic.py`: The complete Python script.
*   `Titanic_Cleaned.csv`: The final, cleaned dataset ready for AI.
